\boxed{\Psi=(S,\rho,K,P)}

* S → Size
* \rho → Density
* K → Kinetic state
* P → Position

What each factor does

The equation can be read as:

\underbrace{\frac{GM}{r^2}}_{\text{gravitational baseline}}
\;
\underbrace{\frac{K}{Mc^2}}_{\text{kinetic-energy fraction}}
\;
\underbrace{\frac{\rho}{\rho_0}}_{\text{density scaling}}
\;
\underbrace{\frac{S_0}{S}}_{\text{size scaling}}
\;
\underbrace{\Phi(P)}_{\text{position/configuration}}
\;
\underbrace{\alpha}_{\text{SDKP coupling}}

This is useful because every factor is dimensionless except the baseline acceleration:

\frac{GM}{r^2}
\rightarrow
\mathrm{m/s^2}

while:

\frac{K}{Mc^2},\quad
\frac{\rho}{\rho_0},\quad
\frac{S_0}{S},\quad
\Phi(P),\quad
\alpha

are dimensionless.

Therefore:

[\Delta g_{\mathrm{SDKP}}]
=
\mathrm{m/s^2}

which passes the basic dimensional requirement.
